## 💎 немного инструментов (Экстремальная оптимизация)

* 🖼️ AVIF to PNGs - Полностью автономный конвертер AVIF → PNG. Весит всего 488 КБ и не требует внешних библиотек.
* 🐬 SEA-WEBP (Delphi/Pascal) - Нативный парсер и ридер формата WebP на чистом Pascal. Никаких внешних libwebp.dll, чистый исполняемый код в модуле PAS.
* 🎬 FLI/FLC to PNGs - Крошечный CLI-конвертер (40 КБ) старых анимаций Autodesk FLIC на чистом C++.
* 🕹️ ToonStruck Game Data Extractor - Инструмент для реверс-инжиниринга и извлечения ресурсов из классической игры ToonStruck (1996).
